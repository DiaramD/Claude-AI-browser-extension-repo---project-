# ORB — Claude AI, Directly In Your Browser

> *No new tabs. No switching apps. Just ask.*

ORB is a browser extension that embeds the full power of Claude AI into your browsing experience. Ask complex questions, scrape live web data, solve problems — all without ever leaving the page you're on.

---

## What ORB Can Do

- **Answer anything** — Complex math, research questions, coding help, writing — Claude's full reasoning capability at your fingertips
- **Scrape & analyze live web data** — Pull structured information from any page. We've used ORB to:
  - Scrape Zillow for distressed properties and active builder zones — organized by address, instantly
  - Pull breaking news from CNN and summarize key facts in seconds
- **Context-aware responses** — ORB sees what you see. Ask questions about the page you're on
- **Voice activation** *(v1.1 — coming soon)* — Talk to ORB hands-free

---

## Getting Started

### Requirements
- Opera GX browser *(Chrome support coming soon)*
- Your own [Anthropic API key](https://console.anthropic.com/)

### Installation

> ⚠️ v1.0 is currently in final packaging. Download will be available at:
> **[https://diaramd.github.io/Claude-AI-browser-extension-repo---project-/](https://diaramd.github.io/Claude-AI-browser-extension-repo---project-/)**

Once released:
1. Download the ORB extension package
2. Open Opera GX → go to `opera://extensions`
3. Enable **Developer Mode** (top right toggle)
4. Click **Load Unpacked** → select the downloaded ORB folder
5. Click the ORB icon in your toolbar
6. Enter your Anthropic API key when prompted
7. Start using Claude directly in your browser
